# План работ

## Шаг 1. Формализация требований и разработка продуктовой и технической спецификаций
*(текущий этап)*

Проведение анализа предметной области и первоначального технического задания с последующей формализацией результатов в виде двух взаимодополняющих артефактов документации:

* **`ARCHITECTURE.md`** — спецификация архитектуры системы: декомпозиция на структурные единицы (контроллеры, сервисы, DTO, слой доступа к данным, middleware, providers), описание их зон ответственности и взаимодействия, контракты маршрутизации, таблица обработки ошибок.
* **`PRODUCT.md`** — продуктовая спецификация: функциональное описание системы, конфигурируемые параметры, критерии приёмки (Acceptance Criteria) по каждому функциональному блоку.

Итог шага — согласованный, непротиворечивый набор спецификаций, пригодный для использования в качестве технического задания для реализации.

## Шаг 2. Реализация по спецификациям Шага 1
Написание кода строго в соответствии с `ARCHITECTURE.md` и `PRODUCT.md`:
контроллеры, `FormRequest`-валидация, сервисы (`FeedbackService`, `AiHandler`), DTO, `FeedbackRepository` (v1, файловая имитация), нотификации (`OwnerFeedbackMail`), middleware (rate limiting, CORS, глобальный обработчик ошибок), заглушки `GET /api/v1/health` и `GET /api/v1/metrics`.

## Шаг 3. Реализация AI-функции (отдельный подпроект)
Сейчас `AiGateway` — заглушка (`AI DONE`). На этом шаге — полноценная реализация: определение языка обращения, перевод при необходимости, реальное обращение к `AI_GATEWAY_URL`, обработка ответа через `AiResponseDTO`.

## Шаг 4. Инфраструктурная доработка
* Конкретные значения переменных окружения (`.env`).
* Настройка списка разрешённых origin'ов для CORS.
* Swagger/OpenAPI документация (`l5-swagger` или аналог).

## Шаг 5. Тестирование
Юнит- и функциональные тесты на все критерии приёмки из `PRODUCT.md`.

## Шаг 6. README
Составление документации после завершения реализации: инструкция по запуску, стек технологий, описание архитектуры, примеры запросов (curl/Postman), описание AI-интеграции и того, что сделано с помощью AI, описание хранения данных.

## Шаг 7. Деплой
Публикация рабочей ссылки на API (Render/Railway/AnyHost/ngrok) либо — если деплой невозможен — инструкция для локального запуска.
