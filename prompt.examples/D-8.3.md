# почтовые отправления

Требования меняются:

## 1. Слой AI
будет выполнять свою задачу, которая достаточно автономная, и будет разобрана позднее.
(Кстати, как будем реализовывать его "задачу" на первых порах, знаешь/помнишь?)

## 2. Соответственно, слой Нотификаций должен

### 2.1. Взять
оригинальную (проверифицированную, естественно), модель Feedback

### 2.2. Отправить
на адрес __владельца__ с копией на $feedback->email письмо:

- тема: "Запрос #[<id>]"
- тело:
- - первые строки:
- - - Ваш запрос #[<id>] получен и принят в работу.
- - - пустая строка
- - - Сообщение:
- - - пустая строка
- - далее ровно $feedback->comment, как он пришёл
- - <подпись>

Где
- <id> генерирует FeedbackService (этот id будет сохранён в FeedbackRepository) по шаблону:
- - YYYYMMDDHHMMSS-<6 случайных цифр>
- <подпись>  - нужно добавить спеки как ENV

### 2.3. Подзадача:
выбрать движок шаблона письма, самый простой (то есть лучше не Blade)
HTML не нужен!
